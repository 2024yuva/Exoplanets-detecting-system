# Light Curves

## What is a light curve?

A light curve is a graph showing how an object's measured brightness changes over time.

For transit observations, the light curve can show a small dip when a planet crosses in front of its star.

## Basic pattern

Normal stellar brightness
→ planet begins transit
→ brightness decreases
→ minimum brightness
→ planet leaves transit
→ brightness returns toward baseline

## Repeated dips

If similar dips occur at regular intervals, astronomers can use the spacing between them to estimate the planet's orbital period.

## Transit depth

The amount of light blocked depends strongly on the relative sizes of the planet and star.

A larger planet generally produces a deeper transit than a smaller planet around the same star.
